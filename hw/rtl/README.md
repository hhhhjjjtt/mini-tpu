## Layout

| Folder | Status | Contents |
|---|---|---|
| `common/` | Reusable | BRAM, AXI4 read master (copied); `unit_frontend.sv`, `sfifo.sv` (new) |
| `matrix_unit/` | New + adapted | Matrix unit (`matrix_unit.sv`, `act_transposer.sv`) around the systolic array (`systolic_array.sv`) |
| `vector_unit/` | New | Vector unit, its `2^-z` ROM and the ROM generator script |
| `scalar_unit/` | New + vendored | Scalar unit: `scalar_unit.sv` (PicoRV32 + memories + mailbox + host registers), `issue_engine.sv` (new); `picorv32.v` (vendored) |
| `dma/` | New | LOAD and STORE units |
| `vmem/` | New | Banked vector memory |

[files.mk](files.mk) is the source manifest used by both [`../sim/Makefile`](../sim/Makefile) and the Vivado flow. `make -s print-srcs` in this folder prints it.

| `scalar_unit/picorv32.v`, `scalar_unit/PICORV32_LICENSE` | [YosysHQ/picorv32](https://github.com/YosysHQ/picorv32) commit `ef203c2b0a3fb793280f5114941416c425c5b461`, ISC license | RV32I control core, unmodified |

Earlier read-only copies used as patterns (`axi_lite_ctrl_regs.v`, `op_fsm.sv` from `fpga/dma/`; the bf16 softmax from `src/softmax/`; the streaming queue engine and its testbenches from commit `cd045ba`, `fpga/streaming/` and `fpga/tb/streaming/`) were removed; read them at those locations. The queue engine was never merged to `main`; it lives only on the `rung4-*` and `hw-streaming-dma-queue` remote branches.
